# Support

## Documentation

Start with the [wiki](https://github.com/seguidodoblado/telegraph-writer/wiki): [installation](https://github.com/seguidodoblado/telegraph-writer/wiki/en-01-4-installation-and-setup), [usage guide](https://github.com/seguidodoblado/telegraph-writer/wiki/en-01-5-usage-guide) and [troubleshooting](https://github.com/seguidodoblado/telegraph-writer/wiki/en-01-7-troubleshooting).

## Getting help

If the wiki does not answer your question, open an issue on [GitHub Issues](https://github.com/seguidodoblado/telegraph-writer/issues) including:

- the version (**About** dialog);
- your distribution and version (for example, Ubuntu 24.04, Linux Mint 22);
- the steps to reproduce the problem.

Do not paste your Telegra.ph access token in the issue. If the problem is with the connection, only state what **Settings → Check connection** shows.
