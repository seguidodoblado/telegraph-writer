# Uso

1. Abre **Ajustes** y configura el access token.
2. Pulsa **Nuevo** y escribe el título y el contenido Markdown.
3. Usa **Vista previa** para revisar el resultado.
4. Usa **Publicar** para crear un artículo.
5. Carga artículos existentes y usa **Actualizar** para modificarlos.

## Borradores

**Guardar** crea un Markdown y un archivo `.telegraph.json` con título, ruta y URL. Los borradores se guardan en `~/Telegra.ph`.

## Imágenes

**Insertar imagen** sube JPG, JPEG, PNG o GIF a Catbox y añade una referencia Markdown. Telegra.ph ha deshabilitado sus nuevas subidas de imágenes, por eso se usa alojamiento externo.

## Publicar frente a actualizar

Si el documento ya tiene una ruta de Telegra.ph, **Publicar** se bloquea para evitar duplicados. Usa **Actualizar**.
