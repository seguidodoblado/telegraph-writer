# Security policy

## Supported versions

Only the latest published *Release* receives security fixes.

## How to report a vulnerability

Open an issue on [GitHub Issues](https://github.com/seguidodoblado/telegraph-writer/issues) describing the problem without including sensitive data such as your access token.

There is no bug bounty programme: this is a personal project maintained in spare time.
