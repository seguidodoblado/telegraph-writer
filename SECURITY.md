# Política de seguridad / Security policy

## 🇪🇸 Español

## Versiones con soporte

Solo la última *Release* publicada recibe correcciones de seguridad.

## Cómo informar de una vulnerabilidad

Abre una incidencia en [GitHub Issues](https://github.com/seguidodoblado/telegraph-writer/issues) describiendo el problema sin incluir datos sensibles como tu access token.

No hay programa de recompensas: este es un proyecto personal mantenido en el tiempo libre.

---

## 🇺🇸 English

## Supported versions

Only the latest published *Release* receives security fixes.

## How to report a vulnerability

Open an issue on [GitHub Issues](https://github.com/seguidodoblado/telegraph-writer/issues) describing the problem without including sensitive data such as your access token.

There is no bug bounty programme: this is a personal project maintained in spare time.
